# 1115 裁判机 详解

### 解题思路

- 题目是模拟类问题：初始给出两个安全数字 a、b，之后 M 轮中每个存活玩家每轮报一个数；若该数已出现过，或不能表示为任意两个已出现数字之差，则该玩家本轮出局。
- 数据组织：`exist` 布尔数组以数字本身为下标标记"是否出现过"（数字范围有限，可开数组）；`record` 数组按出现顺序记录所有已有数字，方便差值判断；`alive` 标记各玩家是否存活。
- 差值判断技巧：新报数 num 合法当且仅当存在已有数字 x > num 使 x − num 也已在集合中，即 `exist[x - num]` 为真——这样把"枚举两两差值"优化为对 record 的线性扫描加一次 exist 查询。
- 出局玩家先暂存到 out 数组，一轮处理完统一冒泡排序（按编号升序）后输出 "Round #i: 编号 is out."，并同步把 alive 置 0，保证同轮内已出局玩家不再被检查、也不影响后续轮次判定。
- 合法数字在判定通过后立即加入 exist 与 record，供本轮后续玩家及后续轮次使用。
- 所有轮次结束后收集存活玩家输出 "Winner(s): ..."，无存活则输出 "No winner."。
- 时间复杂度：每轮每人做一次差值扫描，约为 O(M × N × rcnt)，rcnt 为已有数字个数。

### 代码流程说明

1. 读入初始安全数字 a、b 与玩家数 N、轮数 M；读入 players[i][j] 记录每个玩家每轮报的数。
2. 初始化 exist 与 record：标记 a、b 已出现并存入 record，rcnt = 2；alive 全部置 1。
3. 外层 for 循环处理每一轮：每轮先清空 out 数组（out_cnt = 0）。
4. 内层 for 遍历所有玩家：已出局（!alive[i]）则跳过；取出 num = players[i][round]。
5. 若 `exist[num]` 为真直接判定出局入 out；否则扫描 record 找是否存在 record[j] > num 且 `exist[record[j] - num]` 为真，找不到则出局，找到则把 num 加入 exist 与 record。
6. 本轮检查完毕后，用两重循环对 out 按编号升序排序，然后逐个输出出局信息并把 alive 置 0。
7. M 轮结束后扫描 alive 收集获胜玩家：无存活输出 "No winner."，否则输出 "Winner(s): 编号 ..."。

### 代码流程图

```mermaid
flowchart TD
    Start["开始"] --> Read["读入 a、b、N、M"]
    Read --> Load["读入 players 数组"]
    Load --> Init["exist 标记 a、b，alive 全 1"]
    Init --> Round{"round < M？"}
    Round -- 是 --> Out0["out_cnt = 0"]
    Out0 --> Player{"i < N？"}
    Player -- 是 --> Skip{"玩家已出局？"}
    Skip -- 是 --> Player
    Skip -- 否 --> Num["num = players[i][round]"]
    Num --> Exist{"exist[num] 已出现过？"}
    Exist -- 是 --> Out1["加入 out 数组"]
    Out1 --> Player
    Exist -- 否 --> Scan{"扫描 record 找差值来源？"}
    Scan -- 是 --> Diff{"record[j] > num 且 exist[record[j]-num]？"}
    Diff -- 是 --> Legal["num 合法，加入 exist 与 record"]
    Legal --> Player
    Diff -- 否 --> Scan
    Scan -- 否 --> Out2["无法构成差值，加入 out 数组"]
    Out2 --> Player
    Player -- 否 --> Sort["对 out 按编号排序"]
    Sort --> Print["输出出局玩家，alive 置 0"]
    Print --> Round
    Round -- 否 --> Winners["收集存活玩家"]
    Winners --> Empty{"有获胜者？"}
    Empty -- 是 --> PrintW["输出 Winner(s)"]
    PrintW --> End["结束"]
    Empty -- 否 --> PrintN["输出 No winner."]
    PrintN --> End
```

### 解题流程图

```mermaid
flowchart TD
    Begin["开始"] --> Init2["初始化已出现数字集合与玩家存活状态"]
    Init2 --> RoundLoop{"还有轮次？"}
    RoundLoop -- 是 --> EachPlayer{"还有存活玩家未检查？"}
    EachPlayer -- 是 --> Check["检查玩家报的数字"]
    Check --> Repeat{"数字已出现过？"}
    Repeat -- 是 --> Eliminate["判定该玩家出局"]
    Eliminate --> EachPlayer
    Repeat -- 否 --> DiffCheck{"能由两个已有数字之差得到？"}
    DiffCheck -- 否 --> Eliminate
    DiffCheck -- 是 --> Accept["数字合法，加入集合"]
    Accept --> EachPlayer
    EachPlayer -- 否 --> Report["本轮结束后输出出局名单"]
    Report --> RoundLoop
    RoundLoop -- 否 --> Final["统计仍存活的玩家"]
    Final --> Output2["输出获胜者或 No winner."]
    Output2 --> Finish["结束"]
```
