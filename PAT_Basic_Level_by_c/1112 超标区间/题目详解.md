# 1112 超标区间 详解

### 解题思路

- 题目要求在一维数组里找出所有"超标区间"：连续一段数值都大于阈值 T 的区间，按 "[起始下标, 结束下标]" 输出；若不存在任何超标区间，则输出整个数组的最大值。
- 采用"在线状态机"思路：用一个布尔变量 in_interval 表示当前是否处于超标区间中，边读入边处理，无需把整个数组存下来。
- 区间开始条件：当前值 a > T 且之前不在区间内（in_interval == 0），此时输出 "[i, " 并记录起始。
- 区间结束条件：当前值 a ≤ T 且之前在区间内（in_interval == 1），此时输出 "i-1]"。
- 边界处理：若读完后 in_interval 仍为 1，说明最后一个区间延伸到了数组末尾，需补输出 "N-1]"；若从未进入任何区间（in_interval == 0 且最大值 ≤ T），则输出最大值。
- 同时维护 max_val 以应对"无超标区间"的情形。
- 时间复杂度 O(N)，空间复杂度 O(1)。

### 代码流程说明

1. 读入 N 和阈值 T，初始化 max_val = -1、in_interval = 0、start = 0。
2. for 循环从 i = 0 到 N−1：每次读入一个数 a，先更新 max_val。
3. 若 `a > T && !in_interval`：置 in_interval = 1、start = i，并立即输出 "[i, "。
4. 若 `a <= T && in_interval`：置 in_interval = 0，输出 "i-1]" 表示区间闭合。
5. 循环结束后判断：若 `!in_interval && max_val <= T`，输出 max_val（无超标区间）；否则若 `in_interval` 为真，输出 "N-1]" 闭合延伸到末尾的区间。

### 代码流程图

```mermaid
flowchart TD
    Start["开始"] --> Read["读入 N、T"]
    Read --> Init["max_val = -1，in_interval = 0"]
    Init --> Loop{"i < N？"}
    Loop -- 是 --> Get["读入 a，更新 max_val"]
    Get --> StartC{"a > T 且不在区间内？"}
    StartC -- 是 --> Begin["进入区间，输出 [i, "]
    Begin --> EndC{"a <= T 且在区间内？"}
    StartC -- 否 --> EndC
    EndC -- 是 --> Close["退出区间，输出 i-1]"]
    Close --> Loop
    EndC -- 否 --> Loop
    Loop -- 否 --> NoInt{"不在区间内？"}
    NoInt -- 是 --> AllOk{"max_val <= T？"}
    AllOk -- 是 --> PrintMax["输出最大值"]
    PrintMax --> End["结束"]
    AllOk -- 否 --> End
    NoInt -- 否 --> Tail["输出 N-1] 闭合末尾区间"]
    Tail --> End
```

### 解题流程图

```mermaid
flowchart TD
    Begin["开始"] --> Input["输入数组与阈值 T"]
    Input --> Scan["顺序扫描每个数值"]
    Scan --> Over{"数值大于 T？"}
    Over -- 是 --> InRange{"当前已在超标区间？"}
    InRange -- 否 --> Open["开启新区间并记录起点"]
    Open --> Scan
    InRange -- 是 --> Scan

    Close2 --> Scan
    InRange2 -- 否 --> Scan
    Scan --> Tail2{"扫描结束，末尾区间是否未闭合？"}
    Tail2 -- 是 --> FinishLast["闭合末尾区间"]
    FinishLast --> Judge{"是否存在超标区间？"}
    Tail2 -- 否 --> Judge
    Judge -- 是 --> PrintRanges["输出所有区间"]
    PrintRanges --> Finish["结束"]
    Judge -- 否 --> PrintMax2["输出数组最大值"]
    PrintMax2 --> Finish
```
