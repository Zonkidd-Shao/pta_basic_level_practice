# 1078 字符串压缩与解压 详解

### 解题思路
- 根据首字符 `C`（压缩）或 `D`（解压）选择不同处理分支，首字符后为待处理字符串。
- 压缩：从左到右扫描，用内部 while 统计连续相同字符个数 `cnt`；`cnt > 1` 时先输出数字再输出字符，`cnt == 1` 时只输出字符本身。
- 解压：扫描字符串，遇到数字时用 `cnt = cnt * 10 + digit` 累积出多位数；遇到非数字字符时，若前面有数字则按次数重复输出该字符，无数字则原样输出一次。
- 关键细节：压缩时数字 1 省略不写，因此解压时无数字前缀的字符恰好对应"出现 1 次"，两种处理天然互补。
- 时间复杂度：压缩与解压均为 O(len)，单次线性扫描即可完成。

### 代码流程说明
- 读入操作符 `op`，用 `getchar()` 吃掉换行符，再用 `gets(str)` 读入整行字符串。
- 若 `op == 'C'`：外层 for 遍历字符串，内层 while 统计连续相同字符个数；`cnt > 1` 时先 `printf` 数字，再输出该字符（跳过已统计的重复字符靠 `i++` 实现）。
- 若 `op == 'D'`：for 遍历时先用 while 连续读数字累加得到 `cnt`，若 `cnt == 0` 原样输出单个字符，否则用内层 for 循环把该字符重复输出 `cnt` 次。
- 最后统一输出换行。

### 代码流程图
```mermaid
flowchart TD
    Start["开始"] --> ReadOp["读入操作符 op 和字符串 str"]
    ReadOp --> IsC{"op == 'C' ？"}
    IsC -- 是 --> CompLoop{"遍历 str 未结束？"}
    CompLoop -- 否 --> OutEnd["输出换行"]
    OutEnd --> End["结束"]
    CompLoop -- 是 --> Count["统计连续相同字符个数 cnt"]
    Count --> More1{"cnt > 1 ？"}
    More1 -- 是 --> PrintCnt["输出数字 cnt"]
    PrintCnt --> PrintCh["输出该字符"]
    More1 -- 否 --> PrintCh
    PrintCh --> CompLoop
    IsC -- 否 --> DecompLoop{"遍历 str 未结束？"}
    DecompLoop -- 否 --> OutEnd
    DecompLoop -- 是 --> ReadNum["连续读数字得到 cnt"]
    ReadNum --> IsZero{"cnt == 0 ？"}
    IsZero -- 是 --> PrintOne["原样输出一个字符"]
    PrintOne --> DecompLoop
    IsZero -- 否 --> Repeat["把字符重复输出 cnt 次"]
    Repeat --> DecompLoop
```

### 解题流程图
```mermaid
flowchart TD
    Start["开始"] --> Judge{"操作是压缩还是解压？"}
    Judge -- 压缩 --> ScanC["顺序扫描字符串，找连续相同字符段"]
    ScanC --> Cnt{"段长度大于 1 ？"}
    Cnt -- 是 --> OutC["输出 长度+字符"]
    Cnt -- 否 --> OutS["只输出该字符"]
    OutC --> MoreC{"还有字符段？"}
    OutS --> MoreC
    MoreC -- 是 --> ScanC
    MoreC -- 否 --> End["结束"]
    Judge -- 解压 --> ScanD["扫描字符串"]
    ScanD --> Digit{"当前是数字？"}
    Digit -- 是 --> Acc["累积数字得到重复次数"]
    Acc --> ScanD
    Digit -- 否 --> Ch{"前面有数字吗？"}
    Ch -- 是 --> RepeatD["按次数重复输出该字符"]
    Ch -- 否 --> Once["输出该字符一次"]
    RepeatD --> MoreD{"还有字符？"}
    Once --> MoreD
    MoreD -- 是 --> ScanD
    MoreD -- 否 --> End
```
